# UrbanStyle

UrbanStyle es una pequeña tienda de ropa creada como práctica para trabajar principalmente con JavaScript, además de utilizar HTML y CSS para crear la estructura y el diseño de la página.

Durante el desarrollo se han ido añadiendo diferentes funcionalidades relacionadas con la información del usuario, validaciones, cálculos, temporizadores y almacenamiento de datos.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

La página cuenta con diferentes funcionalidades:

- Obtención del usuario y rol mediante parámetros de la URL.
- Información sobre el idioma y estado de conexión del usuario.
- Generación de un ID de sesión e ID de cliente.
- Obtención y visualización de la fecha actual.
- Validación de los datos del cliente.
- Sistema de membresía.
- Selección de prendas de regalo.
- Validación del correo electrónico.
- Oferta relámpago con un contador de 15 segundos.
- Cálculo del carrito, incluyendo cantidades, precios y formato del resultado.
- Sistema de reseñas que permite guardar la información utilizando localStorage.
- Protección del contenido introducido en las reseñas para evitar la inserción de código no deseado.

## Diseño

Para el diseño se ha utilizado CSS intentando mantener una estructura sencilla y clara, simulando la apariencia de una tienda online.

Se han utilizado colores suaves y una distribución simple para diferenciar las distintas partes de la página y facilitar su lectura.

## Estructura del proyecto

El proyecto está dividido principalmente en tres archivos:

- index.html → contiene la estructura de la página.
- style.css → contiene los estilos y el diseño de la tienda.
- app.js → contiene la lógica y las funcionalidades realizadas con JavaScript.

## Ejecución

Para ejecutar el proyecto solamente es necesario descargar o clonar el repositorio y abrir el archivo index.html en el navegador.

También se pueden utilizar parámetros en la URL para probar algunas de las funcionalidades relacionadas con el usuario y su rol.
